# Анна Морозова — сайт-портфолио фотографа

Учебный проект: одностраничный адаптивный сайт-портфолио фотографа из Казани.
Имя, цены, отзывы и фотографии — демонстрационные данные.

## Запуск

```bash
npm install   # установка зависимостей
npm run dev   # локальный сервер разработки: http://localhost:5173
npm run build # production-сборка в папку dist
npm run preview # предпросмотр production-сборки
```

Требуется Node.js 18 или новее.

## Технологии

- React 18 + Vite 5
- Обычный CSS (CSS Modules для компонентов, глобальные CSS-переменные)
- Без сторонних UI- и анимационных библиотек
- Шрифты (Cormorant Garamond, Inter, кириллица + латиница) лежат локально в `public/fonts`

## Структура

```
public/
  images/     фотографии (WebP, две ширин: 900 и 1800 px)
  fonts/      локальные шрифты
src/
  config/
    formDelivery.js   каналы отправки заявок (Telegram / Google / Formspree)
  lib/
    formSubmission.js отправка формы во все включённые каналы
  data/       ВСЕ редактируемые данные сайта:
    navigation.js     пункты меню
    packages.js       пакеты и цены
    gallery.js        фотографии галереи и категории
    testimonials.js   отзывы (пока — заглушки)
    contacts.js       Telegram / WhatsApp / e-mail (пока — пустые заглушки)
  components/ компоненты секций (jsx + module.css)
  styles/     глобальные стили, переменные, шрифты
google-apps-script/
  Code.gs     готовый скрипт для Google Таблицы (см. раздел «Отправка заявок»)
```

## Что заменить перед публикацией

1. **Фотографии** (`public/images/`). Сейчас там демонстрационные снимки с Unsplash
   (бесплатная лицензия) — они НЕ являются работами Анны Морозовой. Положите
   реальные фотографии под теми же именами файлов (формат WebP, две ширины:
   900 и 1800 px) и обновите `alt`-тексты и размеры `width`/`height`
   в `src/data/gallery.js`, а также `hero` и `about` в компонентах `Hero.jsx`
   и `About.jsx`. Портрет в блоке «Обо мне» тоже временный.
2. **Контакты** (`src/data/contacts.js`). Впишите реальные ссылки на Telegram,
   WhatsApp и e-mail — интерфейс сам покажет кликабельные ссылки вместо
   подписей-заглушек. Реальные номера и аккаунты в учебной версии не выдумывались.
3. **Отзывы** (`src/data/testimonials.js`). Сейчас в блоке нейтральные заглушки.
   Добавьте настоящие отзывы клиентов (с их согласия) — вымышленные цитаты
   публиковать не следует.
4. **Обработчик формы** — подключите каналы доставки в
   `src/config/formDelivery.js` (раздел «Отправка заявок» ниже). До подключения
   посетитель видит честное сообщение, что отправка не настроена.
5. **Цены и пакеты** (`src/data/packages.js`) — легко редактируются в одном файле.
6. **Метаданные** (`index.html`): заголовок, описание, `og:image`.

## Отправка заявок: как подключить и забирать данные

Все каналы настраиваются в одном файле — `src/config/formDelivery.js`.
Включите (`enabled: true`) и заполните хотя бы один; можно включить несколько
сразу — тогда каждая заявка уйдёт во все каналы (например, мгновенное
сообщение в Telegram + строка в таблице).

Что уходит в каналы: имя, контакт, формат съёмки, комментарий, адрес страницы
и время заявки. В форме есть honeypot-поле против спам-ботов: если его заполнил
бот, заявка молча отбрасывается.

### Вариант 1. Telegram-бот (мгновенно на телефон)

1. В Telegram напишите [@BotFather](https://t.me/BotFather) → команда `/newbot` —
   получите токен вида `123456789:ABC-DEF...`.
2. Отправьте своему боту любое сообщение.
3. Откройте в браузере `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates` —
   в ответе найдите `"chat":{"id":123456789}` — это ваш `chatId`.
4. Впишите `botToken` и `chatId` в `src/config/formDelivery.js`.

Забирать данные: они просто приходят сообщением в чат с ботом. Для архива
создайте группу/канал, добавьте туда бота и указывайте её `chatId` — сообщения
будут копиться там.

Безопасность: токен бота читается в исходном коде страницы. Для небольшого
сайта-портфолио это допустимо (худший сценарий — спам в вашем чате; бота можно
пересоздать у @BotFather). Если сайт получает серьёзный трафик — вынесите
отправку за свой серверный эндпоинт, а на сервере держите токен.

### Вариант 2. Google Таблица (все заявки строками)

1. Создайте таблицу → **Расширения → Apps Script**.
2. Вставьте код из файла `google-apps-script/Code.gs`.
3. **Развернуть → Новое развёртывание** → тип «Веб-приложение», кто выполняет
   «Мне», доступ «Все» → скопируйте URL вида
   `https://script.google.com/macros/s/AKfy.../exec`.
4. Вставьте URL в `src/config/formDelivery.js` → `googleSheets.webAppUrl`.

Скрипт сам создаст лист «Заявки» с заголовками: Время, Имя, Контакт, Формат
съёмки, Комментарий, Страница. Забирать данные: обычная таблица с фильтрами и
сортировкой, выгрузка CSV/Excel (Файл → Скачать), уведомления о заполнении
(Сервис → Уведомления) или программно через Google Sheets API, если захотите
строить отчёты.

### Вариант 3. Formspree (письмо на почту)

1. Регистрация на [formspree.io](https://formspree.io) → New form → скопируйте
   ID формы (строка вида `https://formspree.io/f/abcdefgh`).
2. Вставьте ID в `src/config/formDelivery.js` → `formspree.formId`.

Забирать данные: каждая заявка приходит письмом на вашу почту + хранится в
веб-кабинете Formspree (там же экспорт CSV). Бесплатно до 50 заявок в месяц.

## Доступность и производительность

- `lang="ru"`, русские тексты, подписи и alt-тексты
- изображения с `width`/`height` (нет скачков макета), `loading="lazy"` ниже
  первого экрана, адаптивный `srcset`, формат WebP
- лайтбокс с клавиатурой (Esc, ←, →), блокировкой прокрутки и возвратом фокуса
- форма с подсказками об ошибках, `aria-invalid`, переводом фокуса
- анимации появления уважают `prefers-reduced-motion`
- шрифты локальные, снипперты `font-display: swap`
